## B. 漫画章节与小说章节对应依据

| 项 | 结论 |
| --- | --- |
| 漫画 | 第一卷 第一章「与自称是女神的家伙一起转生到异世界！」p5–42，38 页 |
| 小说 | **序章**（para 0–148）+ **第一章**（para 149–711） |
| 顺序 | **`reordered`** —— 漫画把序章整体后置成插叙 |
| 依据 | 30 条可核对的段落锚点，全部写在 `novel_ref.json` 的 `beats[].evidence` 里 |

### B.1 为什么是 reordered

小说顺序：**序章（死亡）→ 第一章（抵达）**。
漫画顺序：**抵达 p6–p9 → 死亡 p10–p19 → 回街上 p20 起**。

漫画先用异世界街景开场（p6 全景、p7–p8 和真兴奋），p9 阿克娅哭着说"回不去"，
p10 首格才出现"没错！真是短暂的人生。"——由此转入天界回忆。

段落本身没被改写，被调换的只是叙述次序。**不写这个字段，下游会以为 p6 演的是序章。**

### B.2 编号不能靠推断（本轮找到的硬证据）

| 目录 | `chapter.json` 的 `id` | `number` |
| --- | --- | --- |
| `m1/v1/ch01`–`ch05` | `ch01`–`ch05` | 第一–五章（一致） |
| `m1/v2/ch06` | **`ch01`** | 第六章 |
| `m1/v2/ch07` | **`ch02`** | 第七章 |
| `m1/v2/ch08` | **`ch03`** | 第八章 |
| `m1/v2/ch09` | **`ch04`** | 第九章 |
| `m1/v2/ch10` | **`ch05`** | 第十章 |

第二卷目录名用全书编号、`id` 用卷内编号、`number` 又是第三套。
**三者对不上，靠 `id` 做跨文件引用必然出错。** 本样张一律用 `chapter_uid`。

### B.3 小说有、漫画没画的三块（"章节为什么短"的答案）

| 小说段 | 内容 | 字数 |
| --- | --- | --- |
| ch01 309–387 | 登记后做了**两周土木工**、泡大众浴场、睡马厩 | 约 3,400 |
| ch01 562–619 | 回程：禁止再用爆裂魔法、惠惠"我只会爆裂魔法"、抱住不放 | 约 2,600 |
| ch01 620–711 | 回公会报告、和真升到四级 | 约 3,900 |

所以第一章短**不是剧本漏写**，是漫画真的跳过了这三块。
其中 309–387 是最大一处——它省掉的不是主线，是**生活质感**。
