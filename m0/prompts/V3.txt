任务：小说事实 + 漫画画面对照，撰写中文视频解说稿（V3：双输入版）

输入：
- 漫画整页图 8 张：page_0005.jpg ～ page_0012.jpg，按文件名顺序阅读（日本漫画，从右到左）
- novel_excerpt.txt（对应小说片段，约 1800 字）

必须遵守的约束（原文）：

以漫画画面作为镜头依据（旁白描述的内容必须在画面中真实存在），
以小说文本作为事实依据（人物关系、因果、背景）。

规则：
1. 小说中有、但漫画画面没有表现的情节，不得作为画面描述写进来。
2. 画面中有、但小说未提及的细节，可以描述，但不得据此编造剧情。
3. 两者冲突时，以漫画画面为准描述"看到什么"，以小说为准描述"意味着什么"。

通用输出规格：
- 覆盖这 8 页对应的剧情段落（与小说片段为同一段剧情），写成连贯的"讲故事"解说，不是逐格报画面
- 中文解说稿，对应 60–90 秒视频旁白，按中文 TTS 约 4.3–4.8 字/秒折算，篇幅 260–400 字
- 分 3–5 段，每段对应 1–3 个画面
- 人物一律用原名（佐藤和真 / 阿克娅）；若无法确定姓名，必须用「戴帽子的女孩」这类占位描述，严禁编造名字
- 页面上印有原书页码，与文件名 page_XXXX 编号不一致；引用画面时一律使用 page_XXXX 文件名编号

输出格式（严格按以下 JSON，segment 按解说顺序排列）：
{
  "version": "V3",
  "model": "<模型标识>",
  "segments": [
    {
      "page": "page_0006",
      "narration": "……",
      "evidence": "画面：他站在城门口抬头看；小说：『欢迎来到新手冒险者的城镇，阿克塞尔』",
      "confidence": "high|medium|low"
    }
  ],
  "char_count": 0,
  "self_reported_uncertainty": "模型自己说明哪里没把握"
}

evidence 是硬要求：每段旁白都要能指回具体画面（画面依据）与小说原文（事实依据）；写不出 evidence 的段落，本身就是"胡编"的强信号。
