任务：只看小说，撰写中文视频解说稿（V2：只看小说版）

输入：
- novel_excerpt.txt（小说第一章片段，约 1800 字）
- 不提供任何图片

通用输出规格：
- 覆盖这段小说文本对应的剧情，写成连贯的"讲故事"解说，不是复述原文
- 中文解说稿，对应 60–90 秒视频旁白，按中文 TTS 约 4.3–4.8 字/秒折算，篇幅 260–400 字
- 分 3–5 段，与 V1/V3 的画面分段粒度保持相当，否则三版无法比较
- 人物一律用原名（佐藤和真 / 阿克娅）；文本未给出姓名的人物用「柜台小姐」这类中性称呼，严禁编造名字

输出格式（严格按以下 JSON，segment 按解说顺序排列；本版无画面，page 字段一律填 "novel"，evidence 填所依据的原文出处，引用起止各 5–10 字原文）：
{
  "version": "V2",
  "model": "<模型标识>",
  "segments": [
    {
      "page": "novel",
      "narration": "……",
      "evidence": "novel_excerpt.txt：「马车驶过石板路……红砖屋」",
      "confidence": "high|medium|low"
    }
  ],
  "char_count": 0,
  "self_reported_uncertainty": "模型自己说明哪里没把握"
}

evidence 是硬要求：每段旁白都要能指回小说原文；写不出 evidence 的段落，本身就是"胡编"的强信号。
