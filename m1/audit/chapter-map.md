# 章节对应表（P0-01）

> 这份表回答一个问题：**这一章漫画的画面，对应小说的哪几段？**
>
> 它是 `novel_ref.json` 的上游。没有它，`novel_ref` 只能靠"看起来像"来填，
> 而"看起来像"正是第六章把「铁笼泡湖净化」写成「哥布林绑票」的原因。
>
> 状态：**只有第一章已核**。其余九章明确标为「未核」，本表**不对它们做任何推断**。

---

## 1. 为什么不能靠编号或标题

一开始最容易犯的错，是假设「漫画第 N 章 = 小说第 N 章」。实测立刻推翻：

| 观察 | 事实 |
| --- | --- |
| 漫画第二章（v1 ch02，p45–74）开头是浴池 + 巨型青蛙 | 这段在小说 **第一章**（para 322–327 浴池、388–443 青蛙战） |
| 漫画第二章标题「替华美的高阶职业带来愉悦！」 | 小说 **没有**这个标题 |
| 小说第二章标题「以这只右手偷取宝物（内裤）！」 | 漫画把这段圣水/内裤生意挪到了 **v1 ch05** |
| 漫画第七章「遭到梦幻竹笋偷袭！」（v2 ch07，8 页） | 该标题在小说第一卷出现 **0 次**（第 13 卷才出现）→ 漫画原创 |

**更直接的证据：目录名与 `chapter.json` 的 `id` 已经不一致。**

| 目录 | `chapter.json` 的 `id` | `number` |
| --- | --- | --- |
| `m1/v1/ch01` … `ch05` | `ch01` … `ch05` | 第一章 … 第五章（一致） |
| `m1/v2/ch06` | **`ch01`** | 第六章 |
| `m1/v2/ch07` | **`ch02`** | 第七章 |
| `m1/v2/ch08` | **`ch03`** | 第八章 |
| `m1/v2/ch09` | **`ch04`** | 第九章 |
| `m1/v2/ch10` | **`ch05`** | 第十章 |

第二卷的目录名用全书编号（ch06–ch10），文件里的 `id` 用卷内编号（ch01–ch05），
`number` 又是另一套（第六章…）。三者对不上，靠 `id` 匹配必然出错——
这是 P0-08「章节身份统一」的直接证据，本样张按 `chapter_uid` 走，不用 `id` 做跨文件引用。

结论：**`chapter_id` 只是工作区身份，不是小说章节身份。**
`ch02` 这个字符串只说明"这是第 2 个工作区"，不说明"这对应小说第二章"。

## 2. 判定方法（每章都按这四步走）

1. **读小说**：`novel_index.json` 给出章标题与全局段区间。注意段号是 `novel.txt` 的
   **全局段号**（0 起），不是章内序号——否则跨章区间无法表达。
2. **读漫画页**：逐页读（`tools/contact_sheet.py` 拼图只用于初筛，
   **判读必须回到单页**——拼图容易看错格序，本样张第一轮就错了一次）。
3. **找事件锚点**：只认"事件"，不认标题。锚点要具体到可以指出第几段：
   一句台词、一个动作、一次因果转折。
4. **写依据**：把锚点段号写进 `novel_ref.json` 的 `beats[].evidence`。
   写不出段号的，就是没核过。

**明确禁止**：用漫画章号推小说章号；用标题字面相似度推；用"上下文看起来合理"补空。

### 3.3 为什么是 `reordered` 而不是 `in_order`

小说顺序是 **序章（死亡）→ 第一章（抵达）**。
漫画顺序是 **抵达（p6–p9）→ 死亡（p10–p19）→ 回到街上（p20 起）**。

漫画把「序章」整体后置成**插叙**：先用异世界街景开场，再回放死因。
段落本身没有被改写，被调换的只是**叙述次序**。

因此 `novel_ref.json` 里写 `order: "reordered"`，并在 `order_note` 里写明
"序章被后置成插叙"。**不写这个字段，下游会以为 p6 演的是序章。**

### 3.4 小说有、漫画没画的三大块

| 小说段 | 内容 | 处理 |
| --- | --- | --- |
| ch01 309–387（79 段 / 约 3,400 字） | 登记后做了**两周土木工**、泡大众浴场、睡马厩、抱怨没有冒险 | `b20` `omitted` |
| ch01 562–619（58 段） | 回程：禁止再用爆裂魔法、惠惠「我只会爆裂魔法」、抱住和真不放 | `b33` `omitted` |
| ch01 620–711（92 段） | 回公会报告任务、和真升到四级 | `b34` `omitted` |

**这就是「漫画第一章为什么短」的答案**：不是剧本漏写，是漫画真的跳过了这三块。
其中 309–387 是本章最大的一处省略，也是"内容不充实"观感的主要来源——
它不是漏了剧情，而是漏了**生活质感**（打工、洗澡、睡马厩）。

> `b33` / `b34` 是否在第二章补叙，**本表不推断**。要在第二章样张里逐页核过才能写结论。

## 5. 这份表怎么用

- `novel_ref.json` 的 `beats[].para` 必须能在本表里找到依据行；
- 写不出依据的 beat，`fidelity` 只能是 `original`（小说没有）或留 `needs_review`；
- 本表与 `novel_ref.json` 不一致时，**以本表的"依据"列为准**去查原文，不要以 JSON 为准。
